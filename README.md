# AI incident documentation audit: public v6 archive

This repository is the privacy-minimized public archive for `AS-v6-20260919_200341` (`v6.0.0`). It contains 1,400 minimal component labels, 300 derived field states, statistics, schemas, synthetic inputs and expected outputs, tests, and a one-command verifier.

Run:

```bash
python verify_release.py
```

The labels were produced through an AI-assisted semantic audit with author confirmation of changed and low-confidence decisions. No independent human gold standard, accuracy estimate, calibration assessment, kappa, AC1, or agreement statistic was produced. The archive demonstrates finite-corpus recomputation and synthetic representational capability only. It is not a validation or accuracy study and is not evidence of safety, risk reduction, governance improvement, or clinical effectiveness.

Long source excerpts, complete webpages, direct source URLs, patient-level data, PHI, browser data, credentials, and local paths are excluded from this public archive. Short evidence excerpts and source locators remain in submission-only supplementary materials.
